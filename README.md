# 复盘驾驶舱前端

这是“刺大布局任务模型”的站点界面。站点本身不保存 API Key、知识库或生成文件，所有私有数据均通过随机令牌连接用户电脑上的本机服务。

## 当前流程

1. 导入每日复盘文件，或一键自爬取指定日期的公开复盘。
2. 本机统一完成文字清洗。
3. 并行生成：
   - Excel：沿用原转换器完整整理，不新增观点。
   - Word：检索本机 RAG，只分析有明确地位和任务的核心个股。
4. Excel 与 Word 独立保存；其中一项失败不会删除另一项。
5. 长任务会记录在当前浏览器会话中，页面刷新后可以继续恢复进度。

## 本地验证

```powershell
npm install
npm run build
npm test
```

正式使用请从桌面的 `启动复盘驾驶舱.cmd` 进入，直接打开站点不会取得本机服务令牌。
