# Privacy

This repository stores source code only.

- Runtime secrets belong in the local environment file; that file is ignored.
- Local databases, generated output, logs, virtual environments, and caches are ignored.
- Personal review records, spreadsheets, Word documents, and the separately maintained site are excluded.
- The environment example contains placeholders only.
- The repository must remain private unless a separate content review approves public release.

Before every push, review staged changes and scan for credentials or personal identifiers.
