# 高标总结与交易心法

> [!abstract] 一句话总纲
> 高标不是“几板”，而是资金在关键节点上，是否围绕一个核心形成了可验证的关系：**竞价态度 → 主动表态 → 板块带动 → 分歧承接 → 隔日再确认**。买入只发生在证据链闭合时；退出只依据预期、地位、板块和承接，不依据成本价或已经赚了多少。

> [!info] 使用方式
> 先看“总纲与证据链”，再看“样本地图”，最后把“盘前—竞价—盘中—盘后模板”用于每日复盘。历史对象统一视作 `SAMPLE`，角色和规则可以复用，名单不能机械复用。

## 1. 交易定位与五层决策

> [!success] 当前定位
> **竞价确认型的周期核心 / 高低切交易者。**主模式只有两类：周期核心的首次确认、高标释放流动性后的高低切确认。辅助模式是计划内的小仓竞价试错；无节点首板、随机低吸、退潮反弹、中位跟风、无助攻一字和缩量容量接力，均不属于当前系统。

### 1.1 当前最重要的矛盾

- 认知端能识别“强”，执行端容易在强转弱时犹豫。
- 目标是高盈亏比，重仓、盈利后加仓和“怕卖飞”会破坏盈亏比。
- 解决顺序不是继续增加口诀，而是先量化：**卖点、仓位、证伪、退潮规则**。
- 每笔交易只保留：**一个主逻辑、一个辅助逻辑、一个明确证伪点**。

### 1.2 每笔交易必须回答四问

1. **为什么是今天？**——节点是什么，资金为什么今天重新分配？
2. **为什么是这个方向？**——它是主线、敌对、伴生、避险还是指数工具？
3. **为什么是这只 `SAMPLE`？**——它是否主动、带动、独立，或至少具备明确地位？
4. **什么现象出现就认错？**——竞价、承接、回封、板块关系和隔日预期中，哪个条件失效就退出？

### 1.3 五层决策顺序

| 层级 | 要回答的事实 | 通过标准 |
|---|---|---|
| 环境 | 赚钱效应、昨日强势溢价、晋级率、跌停扩散、指数风险 | 不能出现多项同步恶化 |
| 节点 | 延续、主升、分歧、退潮、修复，还是新方向试盘 | 能用一句话解释资金为何今天切换 |
| 题材 | 一字上限、换手下限、弹性、容量、主线关系 | 至少有一致性与可交易承接 |
| 个股 | 主动性、带动性、独立性、身位和竞争关系 | 核心优先，最低要求不是杂毛 |
| 交易 | 竞价/回封确认、证伪点、计划损失、退出动作 | 五道门全部闭合才开仓 |

## 2. 高标识别：从板数转向关系

### 2.1 高标的生成公式

> **高标质量 = 节点清晰度 × 题材完整度 × 个股主动性 × 板块带动性 × 隔日确认度**

板数只是结果，不是身份。一个高标如果不能改变同题材对象的定价、不能在分歧时独立、不能获得次日资金确认，就只能记录为高位对象，不能直接升级为核心。

### 2.2 五类角色

| 角色 | 识别证据 | 交易含义 |
|---|---|---|
| 核心 / 大哥 | 率先表态、逆势承接、能改变同题材定价 | 只在首次分歧转一致、第一次加速等关键点评估 |
| 一字兔子 | 隔夜一致性强，打开题材预期上限 | 看它发酵谁；没有换手下限时不把它等同真龙 |
| 换手乌龟 | 吸收真实抛压，能在分歧后主动回封 | 提供可交易下限，优先比较主动性与地位 |
| 小弟 / 补涨 | 被核心带动，属性外溢后跟随 | 用于验证核心，不因数量多就追后排 |
| 敌对 / 伴生 / 工具 | 在主线分歧、指数或避险需求中承担功能 | 角色每日重画，不能沿用旧标签 |

### 2.3 四个高标判断结论

- **高标断板是节点，不是新周期自动成立。**先看断板前是否已有低位布局，再看断板当天和次日二板谁主动。
- **突然平铺首板常是高低切，但指数普涨也会制造平铺。**必须检查高标是否真实释放流动性、低位是否有独立选择。
- **新老不能同屏是观察原则。**旧核心仍吸走全部流动性时，新对象按补涨看；新核心只有取得独立资金和发酵链，才升级为主升核心。
- **首板是试错，二板是第一次共同确认。**没有节点的一进二，即使成功，也不能反过来证明随机首板值得复制。

### 2.4 题材完整性的最小结构

> **一字板负责上限，换手板负责下限；兔子负责打开预期，乌龟负责吸收分歧。**

检查顺序：

1. 是否有明确的一字态度或隔夜资金集中表态？
2. 是否有同属性、可交易、能吸收抛压的换手承接？
3. 高标动作之后，小弟是否主动发酵，而不是全靠共同消息？
4. 一字、换手、弹性和容量是否形成层次，而不是孤立强？

只有兔子没有乌龟：一致性可能缺少真实承接。只有乌龟没有兔子：题材可能缺少压制力和隔夜认可。两者都弱：不把涨停数量当作主线。

### 3.3 2026周期地图

| 周期 | 区间 | 接力结构摘要 | 训练重点 |
|---|---|---|---|

| 周期2 | 3/04—6/08 | 电力、医药、科技、化工等方向轮动，工具人和避险对象较多 | 先识别主线是否仍在，再判断对象是承接还是掩护 |
| 周期3 | 6/15—7/07 | 新旧题材切换，低位对象尝试承接高标释放的流动性 | 用主动性、回封和次日竞价判断是否真正接管 |
| 周期4 | 6/15—8/14 | 高低切、反弹、科技回流和避险并行，周期窗口存在交叠 | 周期按接力链理解，不按自然月份机械切段 |

### 3.4 样本共同结论

1. **先有节点，后有高标。**高标断板、旧主线衰退、冰点修复或题材爆发，才提供资金重新定价的理由。
2. **板数越高，越要看“为什么还能高”。**若只是缩量加速、监管博弈、尾盘硬顶或无小弟发酵，板数反而提高风险等级。
3. **核心会改变市场，而不是只被市场抬高。**上板后小弟增加、题材回流、对手让位，才是带动性的可见证据。
4. **高低切要看提前量。**高标断板前已经主动布局的对象，通常比断板后临时乱拉的对象更值得进入观察池；后者至少等二板确认。
5. **周期尾声仍然可以有很多涨停。**真正的退潮表现是上下级关系失去稳定、补涨高度下降、核心补跌和资金乱窜，而不只是涨停数量减少。

## 4. 买入系统：五道门与两种模式

### 4.1 五道门

| 门 | 必须确认 | 缺失时的动作 |
|---|---|---|
| 1. 环境许可 | 昨日强势溢价、晋级、跌停扩散、指数风险没有同步恶化 | 降级或空仓 |
| 2. 节点明确 | 能解释资金为什么今天重新分配 | 不因图形好开仓 |
| 3. 题材完整 | 有一致性上限，也有可交易承接 | 无换手下限的一字降级 |
| 4. 个股合格 | 有主动性、带动性、独立性中的至少一项，最好两项 | 中位跟风和杂毛排除 |
| 5. 交易可控 | 竞价/回封确认、证伪、计划损失和退出动作已写好 | 不开仓 |

### 4.2 模式A：周期核心首次确认

**适用：**启动后核心初步明确，或主升核心第一次有效分歧后重新获得一致性。

**买入条件：**

- 盘前已进入观察池，并写明“必须一字 / 必须高开 / 可以换手”的基准预期。
- 竞价不低于预期；低于预期时，先等主动翻红或板上确认，不提前用“洗盘”解释弱势。
- 上板时成交可控、回封主动、小弟有响应；依赖其他大哥拉升的，只按跟随处理。
- 只评估首次分歧转一致或第一次加速；高位多次加速不接力。

**建仓：**竞价确认首仓20%—30%；板上进一步确认且板块同步，可加至40%—50%；仅A+主升核心允许分批提高到60%—70%，禁止一次性满仓。

### 4.3 模式B：高低切确认

**适用：**旧高标确实走弱或断板，存量资金开始寻找低位新供应。

**买入条件：**

- 先判断旧核心是正常分歧还是被动死亡；快速修复时，低位对象可能只是陪跑。
- 优先看断板前已主动布局的对象，其次看断板当日独立封板者；断板后临时乱拉至少等二板。
- 次日要有一字态度、换手承接或二板确认；只有首板平铺、没有资金选择时不下单。
- 低位不等于安全，仍需主动性、带动性和可执行的证伪点。

### 4.4 机会等级

| 等级 | 同时满足 | 允许动作 |
|---|---|---|
| A+ | 环境、节点、核心、竞价、板块和退出均清晰 | 分两次建仓，总仓60%—70%以内，单笔账户风险仍受限 |
| A | 节点清晰，至少非杂毛，竞价或板上确认，板块结构基本完整 | 首仓20%—30%，确认后总仓不超过50% |
| B | 观察池内，竞价超预期但逻辑未充分，证伪明确 | 0%—10%观察仓；训练前期优先模拟，不加仓 |
| C | 盘中临时发现、只有形态/消息、无节点或无带动 | 禁止交易 |

## 5. 竞价、封板与回封

### 5.1 竞价只找最优解

盘前先写“应有表现”，竞价只判断实际属于哪一档：

| 情景 | 证据 | 动作 |
|---|---|---|
| 超预期 | 高开/一字/封单/同题材联动高于基准 | 只在观察池内评估，等待板块与成交确认 |
| 符合预期 | 达到最低要求但没有明显增量 | 只做原计划动作，不临时扩大仓位 |
| 低于预期 | 核心低开、封单弱、助攻消失或敌对方向抢流动性 | 立即降级；不为弱势寻找预设外的解释 |

> [!warning] 竞价边界
> 竞价确认的是隔夜态度，不保证全天结果。突发消息、指数急变和板块兑现都可能推翻竞价结论；因此竞价是入场门，不是免检证书。

### 5.2 封板质量

- **爆量检验不参与，回封介入一致性。**第一次爆量是抛压检验，等承接速度、回封主动性和板块同步重新出现。
- **大漏撤单，小漏观察。**“大”和“小”应在盘前结合封单、流通盘和历史成交预先定义，不能事后解释。
- **前三分钟是观察窗。**看成交增速、撤单、封单衰减、连续卖出和回封速度；不同流通盘不机械套用固定秒数。
- **十点前排不到就撤**是接力票的时间止损经验，不适用于所有趋势或午后节点；低位捡漏也不等于安全。
- **一字没有板块助攻不碰。**独立事件对象另按独立逻辑评估，不能把孤立强混入题材接力。

### 5.3 形态只能做辅助证据

- “化虚”与“铁山靠”只有在主升核心、快速修复、主动回封和板块带动同时成立时才有意义。
- 对倒可能放大表面成交；真实换手要看涨停前低位成交、板上成交占比和封单变化。
- 气质、历史股性、名字联想和股本结构只能用于排序，不能替代节点、地位和证伪。

## 6. 卖出与证伪

### 6.1 卖出只看四件事

1. 隔日预期是否兑现？
2. 核心地位是否保持？
3. 板块关系是否仍然支持？
4. 价格与承接是否出现明确证伪？

**成本价、已有利润和“卖飞怎么办”不属于卖出依据。**卖飞是正确执行可能产生的成本；大幅回撤通常来自证伪后没有行动。

### 6.2 隔日动作表

| 盘面情景 | 识别 | 固定动作 |
|---|---|---|
| 高开约5%，板块弱 | 有溢价但题材支持不足，不能独立带回板块 | 竞价或开盘先减半；9:35前不能主动走强并带动，清余仓 |
| 低开约2%，小弟全强 | 可能是核心让位，也可能是小弟反推核心 | 观察3—5分钟；不能主动翻红、承接弱或小弟脱离运行则卖出，禁止加仓 |
| 低于盘前最低预期 | 身份被资金降级 | 可成交先减仓；无主动修复则退出 |
| 冲板失败且板块无响应 | 主动性和带动性同时被证伪 | 第一次明显回落退出，不等成本价 |
| 无承接后翻红 | 反抽改善流动性，但没有新逻辑和持续承接 | 把翻红当退出窗口，不把反抽当反转 |
| 高位利好 | 利好可能已经被主升定价，容易成为集中兑现理由 | 先看是否带来增量和新小弟；没有就优先减仓 |

### 6.3 利润回撤与时间止损（训练版）

- 浮盈不足3%：按普通止损管理，不存在自动利润垫。
- 浮盈3%—8%：从最高浮盈回撤一半，且个股不再主动，至少减仓一半。
- 浮盈超过8%：从峰值回撤4个百分点，或跌破盘前关键承接，减仓。
- 竞价试错9:45前没有主动性，降级或退出；打板后反复开板、跑单放量且板块不加强，按封板失败处理。
- 上述阈值是训练版，不是市场真理。连续记录30笔后，只能在月度复盘调整，盘中不改规则。

> [!danger] 执行口令
> **先卖后评估。**证伪出现时先降低风险，卖出后仍可重新观察；不能因为担心再买成本更高，就让持仓替代判断。

## 7. 仓位与账户停止线

### 7.1 先算账户风险，再算仓位

> **计划仓位 = 单笔允许的账户损失 ÷ 个股计划止损幅度**

训练阶段单笔账户计划风险上限为0.5%—1%。例如计划止损幅度为5%、账户单笔风险上限为1%，理论仓位约20%；考虑跳空、跌停和无法即时成交，实际还要留安全折扣。

### 7.2 仓位框架

| 场景 | 首仓 | 确认后总仓 | 规则 |
|---|---:|---:|---|
| B级观察/试错 | 0%—10% | 不加仓 | 前三个月优先模拟 |
| A级节点机会 | 20%—30% | ≤50% | 只对地位升级加仓 |
| A+主升核心 | 30% | 60%—70% | 至少两次建仓，禁止单票满仓 |
| 分歧/修复 | 0%—20% | ≤30% | 只做核心确认 |
| 退潮 | 0% | 0% | 不设真实资金例外 |

### 7.3 账户停止线

- 单日净值回撤达到2%：当日停止新开仓。
- 一周净值回撤达到4%：下一周前三个交易日仓位上限20%，只做A级机会。
- 月度净值回撤达到8%：停止真实交易5个交易日，复盘全部模式内外交易。
- 从阶段高点回撤达到10%：V1.0暂时失效，降至模拟或极小仓，完成至少20个样本后再恢复。

### 7.4 硬性纪律

- 最多3只观察对象、最多2个交易计划、实际持仓不超过2只。
- 只允许“做对后加仓”：环境未降级、地位升级、板块加强、剩余风险收益合理，四项至少同时成立。
- 禁止向亏损仓位补仓；盈利本身不是加仓理由。
- 模式外交易即使上涨，也不追认其正确性。

## 8. 每日复盘流程

### 8.1 盘前：写预案，不写愿望

- 标记当前阶段：启动 / 主升 / 高潮 / 分歧 / 退潮 / 修复。
- 标记主线、敌对、伴生、避险和指数工具。
- 判断最高标与旧核心：正常分歧还是被动死亡？
- 最多保留3只观察对象、2个交易计划。
- 为每只对象写：主逻辑、辅助逻辑、地位、竞价基准、超预期动作、符合预期动作、低于预期动作、证伪点、最大仓位。

### 8.2 竞价与盘中：只做预案中的最优解

- 看一字数量和质量、封单变化、核心高低开、昨日强势溢价。
- 记录首封、开板、回封、成交、谁先谁后、谁带动谁。
- 高标分歧时，观察中位和低位是承接还是高低切。
- 触发证伪就执行，不因浮亏、已有利润或怕卖飞修改剧本。
- 盘中陌生对象没有进入观察池，不新增逻辑、不临时买入。

### 8.3 收盘：评价决策，不评价结果

回答以下问题：

1. 今天是旧周期延续、主升、分歧、退潮，还是新周期试盘？
2. 今天真正获得一字支持的方向是什么？谁是兔子，谁是乌龟？
3. 谁独立翻红、回封或涨停？谁只是被大哥/指数带动？
4. 高标断板前后，新资金何时完成布局？
5. 今天的亏损是模式损失还是纪律损失？
6. 是否发生了怕踏空、怕卖飞、急于回本或盈利后冲动加仓？
7. 明天唯一最重要的证伪是什么？
8. 记录一只“当时证据正确但没有买”的 `SAMPLE`，只研究证据，不追认结果。

## 10. 心法翻译：把短句变成动作

| 原始心法 | 可执行翻译 |
|---|---|
| 逻辑第一，图形第二 | 先说清资金来源、题材持续性和核心关系，再看K线 |
| 强就是强，弱就是弱 | 盘前写应有表现；盘中不满足就降级，不替持仓找理由 |
| 竞价看的是态度 | 竞价是隔夜投票，核心必须表态；低于预期先降级 |
| 兵不在多，在于精 | 少数观察、最多两只持仓；不把注意力分给杂毛 |
| 重要节点做首板 | 首板只有在资金切换、题材爆发或冰点修复等节点才进入研究 |
| 高标断板为什么是节点 | 断板释放流动性；比较断板前、当日、次日谁更主动 |
| 突然平铺首板就是高低切 | 先排除指数普涨，再看低位是否出现独立选择 |
| 新老不能同屏 | 旧核心未释放前，新对象按补涨处理，不给主升预期 |
| 一个风口，一字上限、换手下限 | 没有上限或下限，题材结构不完整，持续性降级 |
| 爆量检验不参与 | 爆量阶段只观察；等真实承接和主动回封 |
| 兔子是一字先锋，乌龟是换手承接 | 一字看预期，换手看承接；两者角色不能互换 |
| 带动性比涨幅更重要 | 比较关键动作前后小弟、板块和对手的变化，建立因果链 |
| 气质股不等于可买股 | 气质只用于排序，仍需节点、预期差、买点和退出条件 |
| 高位利好，不跑是风险 | 先看利好是否带来增量、新小弟和新空间；否则优先保护交易结果 |
| 妖股死于监管和加速 | 高位连续加速与外部约束同时提高风险，不把监管博弈当买点 |
| 不亏钱等于打板 | 翻译为“不做未经确认的随意交易”，不是打板天然无风险 |
| 满仓主升治百病 | 翻译为注意力和模式集中，实际仓位仍由账户风险倒推 |
| 眼中有思路，心中无顶底 | 有资金关系和证伪边界，不预设绝对顶部或底部 |

> [!tip] 心法的检验标准
> 一句口诀只有同时写出**适用条件、观察证据、失败边界、对应动作**，才算进入交易系统；否则只是盘后解释。

## 11. V1.0训练与验收

### 第一个月：执行重建

- 完成20个交易日的盘前剧本和盘后复核，缺一天不补写。
- 真实交易只做A/A+，单笔账户风险不超过0.5%，模式外交易占比为0。
- 卖点执行率目标≥90%。
- 建立不少于40条竞价样本，记录预期差，不只记录涨跌。

### 第二个月：模式收窄

- 周期核心和高低切各完成至少20个历史案例回放。
- 每个案例标记：节点、竞价、一字/换手结构、主动性、带动性、证伪。
- 真实交易仍只做两种主模式，B级试错继续模拟。
- 模式内交易占比目标≥95%，计划损失与实际损失偏差要可解释。

### 第三个月：小规模验证

- 只有前两个月执行率达标，单笔账户风险才可提高到最高1%；否则保持0.5%。
- 累计至少20笔真实或严格模拟样本，分别计算胜率、盈亏比、期望值、最大连续亏损。
- 月度回撤目标<5%，任何时点不得突破8%干预线。
- 月底只依据样本决定V1.1：保留、删除或修改规则，不依据单次卖飞或单只 `SAMPLE`。

|---|---:|

## 12. 最后保留的边界

> [!quote] 核心句
> **先把错误限制住，再让正确重复发生。看懂市场是能力，按证伪行动才是账户真正拥有的能力。**

- 本笔记来自个人复盘材料与训练版系统，尚未等同于已验证的正期望策略。
- 历史高标的角色会随节点、流动性、监管和市场制度变化；`SAMPLE`名单只用于回看，不构成固定观察池。
- 固定阈值是训练工具，不是市场定律；所有调整放到月度复盘，盘中不改。
- 任何交易计划都必须包含可执行的退出动作，并预留涨跌停、跳空和流动性无法即时退出的风险。
