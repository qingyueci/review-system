## 项目边界

- `frontend/`：Next.js/Vinext 页面组件，负责操作与状态呈现；`frontend/app/lib/review-api.ts` 调用本机 API。
- `backend/`：FastAPI、知识库、模型调用、任务持久化和 Excel/Word 生成；默认仅监听 `127.0.0.1:8765`。
- 根目录启动脚本：创建本机环境、启动服务并打开驾驶舱。
- `docs/rag/`：随项目交付的精选 Markdown 参考资料；当前运行时人工体系导入器仍读取根目录 DOCX，不会自动将 Markdown 载入数据库。

原始代码对应关系：旧的 `review-cockpit-site/` → `frontend/`；旧的 `自动复盘表格生成器/` → `backend/`。历史源码证据仍可通过图中链接追溯到提交 `92876cb`。

## 业务与数据流

### 每日复盘

1. 页面提交日期或文件及生成模式。
2. 后端解析、清洗输入，并对相同运行中请求去重。
3. Word 分支按需检索知识库；Excel 和 Word 两条链路独立执行。
4. 任务状态、耗时和结果分别持久化；失败分支可单独重试，成功分支产物保留。

### 知识库

1. 首次同步建立冻结的高阅读量核心资料与近期窗口。
2. 日常只查找昨日新增内容；窗口移出的帖子归档保留。
3. 人工体系 DOCX 按内容哈希增量导入。
4. BM25 与本地语义检索合并候选，保留来源、链接和检索分数。

### 首板布局分析

1. 确认当日快照及规则版本。
2. 形成完整候选集并执行硬性筛选；不通过的候选保留原因。
3. 通过者才进入独立 RAG 检索与批量分析。
4. 保存规则、证据、分析与导出审计，模型不改写规则判定。
